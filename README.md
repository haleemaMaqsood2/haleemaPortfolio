# Haleema Sadia Maqsood — Developer Portfolio

A responsive dark-theme portfolio built with Next.js 14, React, TypeScript, Tailwind CSS and Lucide icons. Content is based on the supplied CV.

## Run locally

1. Install Node.js 20 LTS (or a compatible Node.js version).
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000

To test the production build:

```bash
npm run build
npm run start
```

## Deploy free on Vercel

1. Create/sign in to GitHub and create a new repository, for example `haleema-portfolio`.
2. Upload these project files to the repository (keep `app/`, `public/`, `package.json` and config files at the repository root).
3. Sign in to Vercel using GitHub: https://vercel.com/signup
4. Select **Add New → Project**, import `haleema-portfolio`.
5. Keep the detected Next.js framework and default build settings, then select **Deploy**.
6. Vercel will provide a public `*.vercel.app` URL. Every push to the connected branch can trigger a new deployment.

## Personalize before publishing

- Confirm that the contact email is suitable for public display.
- Add your GitHub/LinkedIn profile links if you want them shown.
- Add verified Play Store/App Store project URLs if you want project links.
- The CV is included at `public/Haleema-Sadia-Maqsood-CV.pdf` and linked from the hero.
